Drop it into your scene

import * as THREE from 'three';
import { Lumo } from './lumo.js';

const lumo = new Lumo({ pixelRatio: renderer.getPixelRatio() });
scene.add(lumo);

lumo.setState('majestic');        // idle · think · speak · happy · majestic · sleep
lumo.gaze(0.4, 0.2);              // -1..1, or null to let it wander
lumo.set({ wingSpread: 0.6 });    // ease any rig target directly
lumo.speakLevel = analyserLevel;  // drive the beak from TTS audio

const clock = new THREE.Clock();
renderer.setAnimationLoop(() => {
  lumo.update(clock.getDelta());
  renderer.render(scene, camera);
});
react(state, s)
Play a mood for a few seconds, then return to the previous one. Tapping Lumo here calls react('happy').
pulse() · blink()
One-shot beats: a ring of light, or a single blink. Blinks also happen on their own.
lumo.parts
Named rig: head, eyes.left/right (ball, lidTop, lidBottom), beak.jaw, crest, wings.left/right (primaries, coverts), tail, halo. Animate them with GSAP or your own timeline.
lumo.targets
The values each frame eases toward. Tween these for smooth, layered motion.
'statechange'
Event fired on every mood change, with state and previous.
